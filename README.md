# Dev Journal

## What this is
This is a public *casual* style dev journal ^-^

Key points:
- Every day I will write in it, even if no dev work was done.
- I try to make each entry new and entertaining for anyone who reads it, specifically my future self.
- For me, each entry is (or at least should be) a reward to write, not a chore.
